Story: the three classes are almost perfectly balanced (~390 images each), so the model is not biased toward one class and plain accuracy is a fair metric, though we also report macro F1, precision and recall.

Feature 1 – Greenness index

1 · Upload bulk training data

Select many images of the same class, choose the label and upload. Files are validated, resized to 224×224, saved to data/uploads/ and recorded in the SQLite database.

2 · Trigger retraining

Retraining loads the current model as the pre-trained model, fine-tunes it on the new uploads plus a replay sample of the original data, evaluates it on the test set and promotes it only if accuracy does not drop. It also starts automatically once – new images are pending.
